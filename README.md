A chess engine in at most 4,096 bytes of Python (this entry starts from the kit's starter and grows a real search). It plays the make.fun house gauntlet through the env API: fixed-depth alpha-beta, no clock, no model calls, standard library only.

## Run it

```sh
MAKEFUN_ENV_URL=<env url> python3 main.py
```
